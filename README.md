# نظام إدارة الطلبات — نسخة عربية

نسخة بسيطة من نظام إدارة الطلبات تعمل كموقع على GitHub Pages، مع حفظ قاعدة البيانات في ملف `database.json` داخل مستودع GitHub.

## الملفات
- `index.html` — الموقع كاملًا في ملف واحد.
- `config.js` — الإعدادات القابلة للتعديل.
- `database.json` — قاعدة البيانات المشتركة.

## التشغيل
1. أنشئ مستودعًا على GitHub.
2. ارفع الملفات الثلاثة.
3. فعّل GitHub Pages من إعدادات المستودع.
4. افتح الموقع.
5. أدخل اسم مستخدم GitHub ورمز وصول شخصي بصلاحية Contents: Read and write للمستودع.

> ملاحظة: هذه النسخة مناسبة للاستخدام البسيط وتنظيم العمل. GitHub Pages نفسه لا يستطيع الكتابة إلى المستودع بدون صلاحية API، لذلك يستخدم الموقع رمز GitHub الذي تدخله في جلسة المتصفح.
